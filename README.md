# 家無しタロ リンクページ

TikTokのプロフィール欄に貼るためのリンクまとめページ。

**公開URL: https://ienashi-taro.github.io/**

---

## ⚠️ このリポジトリは公開（PUBLIC）です

誰でも中身を見られます。**次のものは絶対に置かないでください。**

- 本名・住所・電話番号・メールアドレス
- 会社名・屋号・事業に関する情報
- パスワード、APIキー、Webhook URL などの鍵

### 記録を残すときの注意（重要）

変更の記録（コミット）には**作った人の名前とメールアドレスが自動で残り、それも公開されます**。
このリポジトリは匿名の作者に固定してあります。**設定を変えないでください。**

```
作者名: taro
メール: taro@users.noreply.github.com
```

確認するとき: `git log --format='%an <%ae>'`
本名やGmailが出てきたら、その記録は公開してはいけません。

## 直したいときの場所

`index.html` を開くと、直す場所に目印のコメントが入っています。

### リンク先や文字を変える

`▼ ここからボタン4つ` 〜 `▲ ここまでボタン4つ` の間。ボタン1つはこの形です。

```
① たろオープンチャット
   href="https://..."                              ← 飛び先のURL
   <span class="ttl">たろオープンチャット</span>      ← 大きい文字
   <span class="sub">「タロの共有部屋」に参加する</span> ← 小さい文字
```

### 名前・ひとことを変える

`▼ ここからプロフィール` 〜 `▲ ここまでプロフィール` の間。

### アイコン画像を設定する

`assets/avatar.png` を差し替えるだけ。HTMLを触る必要はありません。
画像が無くなった場合は「タ」の文字アイコンが自動で表示されます。

- 正方形の画像を推奨（縦横が違うと中央で切り取られます）
- 400×400px 程度あれば十分
- **置く前に写真の撮影場所などの記録（Exif）を消すこと**。スマホの写真には位置情報が入っていることがあります

## 公開のしくみ

GitHub Pages。`main` ブランチに push すると、**1〜2分で公開ページに反映**されます。URLは変わりません。

検索避け（`noindex`）を入れているので、Google等の検索結果には出ません。リンクを知っている人だけが見られます。
